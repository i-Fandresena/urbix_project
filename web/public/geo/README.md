# Hero globe map data

`natural-earth-countries.json` contains simplified country boundaries from the
Natural Earth 10m admin-0 countries dataset. The source pack was found in the
local `God's_Eye/` repository; the map data itself is Natural Earth data, not a
God's Eye View application asset.

- Upstream: [nvkelso/natural-earth-vector](https://github.com/nvkelso/natural-earth-vector)
- Source: `ne_10m_admin_0_countries`
- Upstream commit: `ca96624a56bd078437bca8184e78163e5039ad19`
- Terms: [Natural Earth public-domain terms](https://www.naturalearthdata.com/about/terms-of-use/)
- Credit: Made with Natural Earth.

The hero renders the country outlines on a local canvas. Its orbiting
satellites and color-changing lights are illustrative decoration, not live
satellite positions, signal reports, or prevalence statistics.
