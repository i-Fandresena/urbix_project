# Hamarino

Next.js application for **Hamarino by Urbix**. Read the [project README](../README.md) for setup and the [product specification](../PRODUCT_SPEC.md) for the flow, source policy, security and limitations. Claude Code's handoff is in [../CLAUDE.md](../CLAUDE.md).

Run `npm install`, copy `.env.example` to `.env.local`, add a newly created Gemini key locally, then run `npm run dev`. Without a key, use **Voir un exemple** for the clearly labeled simulation.
