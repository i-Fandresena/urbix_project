# Transcription de travail

`Hackathon_Besoins.txt` est une transcription automatique faite localement à partir de la vidéo du dossier, avec Whisper `base` (français détecté). Quelques mots sont mal reconnus. Elle sert à la recherche et à la synthèse ; vérifier à l'écoute avant toute citation littérale ou décision fondée sur un nom propre.
